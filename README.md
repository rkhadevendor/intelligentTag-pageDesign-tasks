# Allocate Comps Page

A lightweight, mobile-first HTML/CSS mock of an “Allocate Comps” screen.  
Designed with simple CSS (viewport units, no media queries) and no JavaScript.

## ✨ Features

- Top nav with back button and build string
- “Comp-Eligible Total” summary
- Apply-Comps cards (EasyDine, eComp, Club Dollars) with status tags
- Smart Allocate / Reset action buttons
- Bottom summary + prominent **CONTINUE** CTA
- Fixed footer with quick actions (Calculator, Reset, Info)
